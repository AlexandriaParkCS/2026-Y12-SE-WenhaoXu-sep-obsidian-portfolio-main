The project will follow an Agile methodology, allowing for flexibility, continuous feedback, and iterative improvement. Weekly sprints will include planning, development, testing, and review.

**Project Phases**

The main phases of the project will be:

- Discovery – Define student and educator needs, research existing fire safety education tools and gamification approaches.
- Design – Create wireframes, scenario flowcharts, and user journey diagrams.
- Development – Build core features (scenario engine, decision-based gameplay, progress tracking, feedback system).
- Testing – Conduct unit testing, usability testing with target age groups, and bug fixing.
- Deployment – Host the application online and finalise documentation.
