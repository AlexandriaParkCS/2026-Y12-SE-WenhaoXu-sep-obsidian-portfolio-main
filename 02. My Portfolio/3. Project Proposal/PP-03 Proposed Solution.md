Fire Safety Education will be a Python-Flask-based Progressive Web Application (PWA) that allows users to:

- Browse and interact with fire safety scenarios
- Make decisions within simulated emergency situations
- Progress through gamified learning modules
- Receive feedback on their choices and outcomes

**Key Features**

The key features of Fire Safety Education are:

- Functional:
    - Interactive scenario engine, decision-based gameplay, feedback system.
- Performance:
    - Fast load times, responsive user interface
- Security:
    - 
- Privacy:
    - Compliance with the Australian Privacy Act 1988.

**User Experience**

The interface will be visually engaging and age-appropriate, designed with young students in mind. Users will be able to access the application from any device using only a web browser and basic internet access. Gamified elements such as scenarios, choices, and outcome feedback will keep students engaged and maybe encourage repeated use, reinforcing fire safety knowledge in a practical and memorable way.

**Technologies**

Fire Safety Education will be based on the following 3rd-party technologies:

- Backend: Python
- Frontend: Pygame
