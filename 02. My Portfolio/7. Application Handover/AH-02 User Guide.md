# Fire Safety Education User Guide
## 1. Introduction
Welcome to Fire Safety Education!

This game is designed to help players learn about fire safety through interactive scenarios and decision-making. Throughout the game, you will encounter different situations regarding a fire, where you must identify hazards, make safe choices, and respond appropriately to fire emergencies. The aim is to improve your understanding of fire prevention, emergency procedures, and safe evacuation practices.

For instructions on downloading and installing the Fire Safety Game on macOS, refer to the **Fire Safety Education Installation Guide**.
## 2. System Requirements
The game is designed to run as a standalone application.
#### Supported Platforms
- macOS
- Windows (Coming Soon)

A separate version of the game may be provided for each operating system.
## 3. Starting the Game
When you open the game, you will be taken to the main menu.

The main menu contains three options:

#### Start Game
Select "**Start Game**" to begin playing. You will be introduced to a series of interactive fire safety scenarios.
#### Options
Select "**Options**" to view or change available game settings.
#### Quit
Select "**Quit**" to close the game.

## 4. Interacting with the Game
The game is primarily controlled using the mouse.
### Mouse
Use the mouse to:
- Select menu buttons.
- Click on interactive objects.
- Select answers or decisions.
- Navigate through menus.

When the mouse cursor is moved over an interactive button, the button may change appearance to indicate that it can be selected.

Click an option to continue.

## 5. Learning from Mistakes
Making an incorrect choice is part of the learning process. If you select an unsafe option, the game will provide feedback explaining the potential problem and what a safer response would be. You can use this feedback to improve your understanding and try the scenario again.

## 6. Important Safety Information
This game is intended for educational purposes only!

The scenarios in the game are simplified representations of fire safety situations. In a real emergency, always follow the instructions of emergency services and responsible adults or authorities. 

For more information, consider visiting websites like https://www.fire.nsw.gov.au/ (NSW Fire + Rescue).

## 7. Exiting the Game
To exit the game, select "**Quit**" on the main menu. Do note that you cannot return to the game's main menu screen in its current state after pressing "**Start**".

Alternatively, you may close the application using your operating system's standard window controls.
