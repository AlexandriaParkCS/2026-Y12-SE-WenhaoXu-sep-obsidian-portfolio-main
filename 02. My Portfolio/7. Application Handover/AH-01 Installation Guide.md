# Fire Safety Education Installation Guide

## 1. Introduction
This guide explains how to download and install the Fire Safety Game on your computer.

The game is currently only available on **macOS**. 

Download the version that matches your operating system.
# 2. Installation on macOS
## Step 1: Download the Game
Download the **Mac version** of the Fire Safety Game from the location provided by the game developer. The downloaded file will be a `.zip` file.
For example:
`Fire Safety Game Mac.zip`

## Step 2: Extract the Game
Locate the downloaded `.zip` file in your **Downloads** folder. Double-click the file to extract it. This will create the Fire Safety Game application.

For example:
`Fire Safety Game.app`
## Step 3: Open the Game
Double-click **Fire Safety Game.app** to launch the game.

The first time you open the application, macOS may display a security warning because the application was created by an independent developer and may not be verified by Apple. If this occurs, follow the instructions provided by macOS to allow the application to open.

## Step 4: Play the Game
Once the game opens, you will be taken to the main menu.
Select:
- **Start Game** to begin.
- **Options** to change available settings.
- **Quit** to close the game.
No additional installation of Python should be required when using the standalone application.
